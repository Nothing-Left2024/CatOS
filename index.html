欢迎使用 HtmlMaker

        
用积木搭建网页，无需写代码。
通过拖拽、组合积木块，即可创建 HTML、CSS、JavaScript 页面。

        
本引导共 12 步，将从界面认识到实战示例，带你完整掌握用法。

      


      
      

        

        
认识界面布局

        
整个界面分为四个区域：

        
    
          
  • 顶栏：Logo、页面切换标签、撤销/重做、主题、关于、导出
    • 
          
  • 左侧：分类竖栏 + 积木调色板
    • 
          
  • 中间：工作区（搭建积木的地方）
    • 
          
  • 右侧：代码预览 / 渲染预览面板
    • 
        

        
HTML 页的工作区顶部还有「页面标题」输入框，可设置网页标题。

      


      
      

        

        
三页编辑，各司其职

        
顶部切换 HTML / CSS / JS 三个编辑页：

        
    
          
  • HTML 页：搭建页面结构（容器、文本、媒体、表单、列表、表格）
    • 
          
  • CSS 页：编写样式（选择器 + 样式属性积木）
    • 
          
  • JS 页：添加交互（事件、控制流、DOM、运算、字符串等）
    • 
        

        
三个页面互相独立，切换时数据自动保存，可随时来回切换。

      


      
      

        

        
调色板与分类导航

        
左侧调色板按分类展示所有可用积木：

        
    
          
  • 最左侧 竖栏：分类图标+文字，点击快速跳转到对应分类
    • 
          
  • 中间 积木列表：显示该分类下所有积木
    • 
          
  • 顶部 搜索框：输入关键词（如「按钮」「颜色」）快速查找
    • 
        

        
鼠标悬停积木可查看用途说明；竖栏图标会高亮当前分类。

      


      
      

        

        
拖拽添加积木

        
按住左侧调色板里的积木，拖动到中间工作区：

        
    
          
  • 拖到工作区空白处：作为顶级积木
    • 
          
  • 拖到某个容器积木内部：作为子积木（嵌套）
    • 
          
  • 拖到两个积木之间：插入到该位置（出现半透明预览）
    • 
        

        
注意：单击积木不会添加，必须拖拽。拖动时会显示半透明预览。

      


      
      

        

        
在积木内编辑参数

        
很多积木带有内联输入框，点击即可编辑：

        
    
          
  • HTML 链接积木：可输入 href 链接地址、target 打开方式
    • 
          
  • JS 事件积木：可输入选择器（如 #btn）
    • 
          
  • 变量积木：可输入变量名和值
    • 
          
  • 运算积木：可输入 A、B 两个操作数，结果存入指定变量
    • 
        

        
输入框有灰色占位符提示格式，如 #btn、1000、hello。参数会自动替换到生成的代码中。

      


      
      

        

        
嵌套、移动与删除

        
积木可以层层嵌套，构建复杂结构：

        
    
          
  • 容器积木（div、section、ul 等）可放入子标签
    • 
          
  • 拖动已有积木到新位置可重新排列或改变嵌套关系
    • 
          
  • 拖回左侧调色板：删除该积木
    • 
          
  • 选中积木后按 Delete 键：删除
    • 
        

        
不兼容的嵌套会自动提示并拒绝（如把视频属性放进段落）。

      


      
      

        

        
右键菜单：更多操作

        
右键点击积木或工作区，打开自定义菜单：

        
    
          
  • 复制 / 粘贴 / 原地复制：快速克隆积木
    • 
          
  • 删除：移除当前积木
    • 
          
  • 编辑标签属性：href、src、placeholder、type 等
    • 
          
  • 编辑样式：颜色、尺寸、边距、定位、悬停样式
    • 
          
  • 编辑文本内容：直接输入段落、标题、按钮文字
    • 
        

        
点击页面其他位置或按 Esc 关闭菜单。不同类型积木的菜单选项不同。

      


      
      

        

        
接下来：实操练习

        
理论部分结束，现在跟着引导实际操作一遍：

        
    
          
  • 切换 HTML / CSS / JS 三个编辑页
    • 
          
  • 从调色板拖一个积木到工作区
    • 
          
  • 体验真实的拖拽与搭建流程
    • 
        

        
点击「开始实操」进入交互式引导，高亮元素会指引你每一步操作。

      


      
      

        

        
CSS 样式编辑

        
切换到 CSS 页，用积木搭建样式规则：

        
    
          
  • 先拖入选择器（标签 / 类 / ID）作为起点
    • 
          
  • 再拖入样式属性积木（颜色、尺寸、边距、定位等）
    • 
          
  • 点击属性积木内的输入框修改值（颜色用取色器）
    • 
          
  • 右侧实时显示生成的 CSS 代码
    • 
        

        
样式属性积木必须放在选择器内，像 CSS 规则 { 属性: 值 } 一样。多个选择器互相独立。

      


      
      

        

        
JS 交互编辑

        
切换到 JS 页，用积木搭建 JavaScript 逻辑：

        
    
          
  • 事件积木（页面加载、点击、输入）作为顶级起点
    • 
          
  • 控制流（如果、循环、判断分支）可嵌套子语句
    • 
          
  • 运算 / 字符串 / 数组 / 对象 / JSON 等分类提供丰富操作
    • 
          
  • DOM 操作修改元素，输出积木打印日志/弹窗
    • 
        

        
事件积木只能放顶层；「等待 N 秒」需放在事件内才会暂停后续代码；运算/字符串结果会存入你指定的变量。

      


      
      

        

        
预览、导出与快捷键

        
完成搭建后，可以预览、导出和高效操作：

        
    
          
  • 右侧 「预览」按钮：切换到渲染视图（含 JS 执行）
    • 
          
  • 「复制」按钮：复制生成的代码
    • 
          
  • 右上角 「导出」：完整 HTML / 仅 CSS / 仅 JS / 项目 JSON
    • 
          
  • Ctrl+Z / Ctrl+Y：撤销 / 重做　Ctrl+C/V/D：复制/粘贴/原地复制
    • 
          
  • Delete：删除选中积木　Ctrl+S：手动保存
    • 
        

        
项目数据自动保存到浏览器本地，刷新不丢失。准备好了？点击「开始使用」开启你的积木编程之旅！
